다른 PC 나 새 세션의 Claude 가 이 파일만 읽고 바로 이어서 일할 수 있게 `docs/HANDOFF.md` 를 갱신합니다.
(하네스 SessionStart 훅이 다음 세션 시작 때 이 파일 앞부분을 자동으로 읽어요. 그래서 중요한 것을 위에 씁니다.)

먼저 확인: `git status`, `git log --oneline -10`, `git diff --stat`, 그리고 `.harness/done-criteria.md` 가 있으면 읽기.

형식 (40줄 안에 핵심이 다 들어가게):
```markdown
# HANDOFF — <날짜 시각> / 브랜치 <branch>
## 지금 상태 (한 줄)
## 다음에 할 일 (순서대로, 바로 실행 가능한 단위)
1.
## 완료 조건 / 남은 테스트
## 진행 중 결정과 이유
## 주의 (건드리면 안 되는 것, 실패했던 시도)
## 실행 명령 (빌드/테스트/서버)
## 이번 세션에서 바꾼 파일
```
기존 HANDOFF.md 가 있으면 "지금 상태 / 다음에 할 일" 은 덮어쓰고, 지난 내용은 맨 아래 `## 이전 기록` 으로 3개까지만 남기세요.
작성 후 커밋할지 사용자에게 물어보세요.
