`$ARGUMENTS` 작업의 완료 조건을 합의합니다. **이 단계에서는 코드를 수정하지 않습니다.**

1. 관련 코드를 Read/Grep 으로 확인합니다 (엔티티, 서비스, 기존 테스트).
2. 아래 형식으로 제시하고 승인받습니다.
   ```markdown
   # 완료 조건: <작업명>
   ## 통과해야 할 테스트
   - [ ] <테스트 클래스>#<메서드> — <검증하는 동작> (신규/기존)
   - [ ] 경계값: ...
   - [ ] 실패 케이스: 권한 없음 / 존재하지 않음 / 중복 요청 ...
   ## 실행 명령
   - ./gradlew test --tests "..."
   ## 범위 밖 (이번에 안 하는 것)
   ```
3. 승인되면 `.harness/done-criteria.md` 에 저장합니다. (컴팩션 때 하네스가 자동 보존해요)
4. 그다음 테스트 → 구현 순서로 진행하고, 끝날 때 체크박스를 실제 실행 결과로 채웁니다. 마지막엔 verifier 에이전트로 검증할 수 있어요.
