---
자리를 비운 사이 모인 결정을 처리하는 단계예요.

1. `.harness/pending-decisions.md` 를 읽고 미해결 항목(`- [ ]`)을 정리해 보여주세요: 질문 / 막힌 이유 / 선택지(추천) / 같이 보류한 작업.
2. AskUserQuestion 으로 한 번에 물어보세요 (한 번에 최대 4개, 추천안을 첫 번째 선택지로). 서로 의존하는 결정은 먼저 정해야 하는 것부터.
3. 답을 받으면 각 항목을 `- [x] D<번호>: ... → 답: <결정>` 으로 바꾸세요. 아키텍처 수준 결정이면 docs/decisions.md 에도 한 줄 추가.
4. 보류했던 작업을 결정에 맞게 다시 계획해서 보여주고 (계획 게이트 대상이면 Plan 모드로), 승인되면 이어서 진행하세요.
